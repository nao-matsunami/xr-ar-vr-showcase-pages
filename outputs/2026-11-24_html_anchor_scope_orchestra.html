Anchor Scope Orchestra

派生試作: 一つの root anchor に対して複数の音・UI・オブジェクトを相対配置します。root の補正は全パートへ伝わりますが、局所の編集は root の再配置に変換しません。

舞台をクリックすると root anchor を置き直します。各子は root 相対で描かれるため、世界理解の補正時に群れとして動きます。

scope ledger
使い分け
  1. 一枚の案内板・複数パネルは一つの anchor に相対配置する。
  2. 離れた物理地点は複数 anchor に分け、相対誤差を隠さない。
  3. root の更新を子の個別保存へ焼き込まない。

次に足すなら、実 XRFrame から root の pose を得て音源・DOM overlay・3D モデルを同じ相対座標で更新し、anchor のロスト時はパートを一括で保留にします。
