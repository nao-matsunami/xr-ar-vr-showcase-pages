Visibility Pose Conductor

XR の表示状態に合わせ、描画・入力・pose の扱いを切り替える自作ミニ試作です。これは実機 API の代わりに状態を再現し、古い観測を「現在」として確定しない判断を触れます。

青い点は fresh pose。visible だけが input を受け、visible-blurred は意図を保留、hidden はレンダリングと入力を止めます。ボタンで送った intent の receipt を右で確認してください。

session receipt
次に足すなら
  1. 実機で session.visibilityState と visibilitychange を購読する。
  2. XRFrame.getViewerPose() を frame callback 内だけで読み、状態変化後は次の fresh frame を待つ。
  3. 保留 intent は自動実行せず、visible 復帰後に再確認する。
