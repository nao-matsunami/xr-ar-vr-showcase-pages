Frame Freshness Studio

XR の pose・hit-test・入力を別々の時刻から寄せ集めず、同じ frame の証拠だけを commit に使うための自作ミニ試作です。

規則: reset 後、または pose / hit が同一 frame でなければ placement は pending。色が揃った frame だけ緑の印を残します。

frame receipt

次に足すなら

  1. XRFrame.getViewerPose() と getHitTestResults() の実値を同じ callback で束ねる。
  2. visibility change 後は新しい frame を得るまで confirm を無効にする。
  3. frame 番号でなく、実際の reference-space と input source も receipt に含める。
