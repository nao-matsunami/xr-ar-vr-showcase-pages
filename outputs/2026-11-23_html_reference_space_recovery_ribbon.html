Reference Space Recovery Ribbon

追跡が途切れた際に、最後の pose を黙って使い続けないための派生試作です。下のボタンで状態を進め、空間の見え方と UI の扱いを比べます。

space receipt
  • tracking: 新しい pose を描画へ渡す。
  • limited: 候補表示は残すが、確定を止める。
  • lost: stale pose を固定せず、空間依存の操作を保留する。
  • relocalized: 参照を更新し、以前の印を再確認する。

次に足すなら、実機の XRReferenceSpace.reset と anchor/hit-test の再取得を結び、再配置が必要なオブジェクトだけを通知します。
