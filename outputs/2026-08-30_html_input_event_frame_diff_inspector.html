Why This Exists

WebXR の入力は DOM 風の select events と XR frame 上の pose/gamepad poll が同居する。アプリの action は、event 受信だけで即決せず、近い frame の gamepad 状態で裏取りできると復旧しやすい。

  • event が早い時は短い hold window で frame confirmation を待つ。
  • poll が欠けた時は visual-only に落とし、次 frame で再判定する。
  • late confirmation は二重発火を避けるため event id で束ねる。
