TRUSTED UI ACTIVE

通常の XR 表示です。アプリが描画し、XR input を処理できます。ただし信頼済み UI を模したページ内ダイアログは作らず、OS / browser の UI はアプリの外にあるものとして扱います。

privacy receipt
visibility: visible
frame policy: native cadence
XR input: processable
page action: render scene
実機では session.visibilitychange を受け、hidden と visible-blurred で input を停止します。ポーズや視線から信頼済み UI の選択を復元しようとしないことが重要です。
