Input Profile Receipt Mixer

派生試作: input profile を「何でも同じ controller」として扱わず、動作に必要な semantic capability と action receipt を小さく組み合わせます。

profile は UI の飾りではなく、target ray / primary action / haptics などの互換性を評価する手掛かりです。未知 profile は推測で確定せず、最小機能へ落とします。

capability receipt

発展案

  1. 実際の inputSource.profiles から公式 registry の model を非同期取得する。
  2. ユーザー割り当てを保存する前に、profile ではなく意味的 action 名を記録する。
  3. haptic actuator は存在と許可を別々に検査し、失敗を成功に見せない。
