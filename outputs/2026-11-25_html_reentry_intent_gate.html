Re-entry Intent Gate

フォーカスを失った XR セッションへ、保留していた操作を勝手に流し込まないための派生試作です。状態を進め、復帰後にも明示確認が必要なことを試してください。

これは外部デモの転載ではなく、session visibility から導いた自作の操作ポリシーです。復帰は「実行許可」ではなく「再確認できる状態への遷移」として扱います。

intent receipt
発展案
  1. 実機の visibilitychange でキューを needs-confirm に遷移する。
  2. hit-test / anchor の候補は fresh frame で再評価してから確認 UI を出す。
  3. 入力 source が変わった場合も、古い select を別 source の実行に変換しない。
