静的 layer の redraw と WebGPU texture set の「アプリが描く → GPU 完了 → compositor が使い終える」を分離して、次に recycle してよい時点を可視化します。値はモデルであり、実機 API の代替ではありません。

入力

仕様では resource loss により needsRedraw が true になり、非 projection layer は redraw event を受けます。WebGPU binding は compositor 利用が終わるまで texture backing resource を解放しません。
