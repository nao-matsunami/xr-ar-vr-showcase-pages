Input Source Relay Desk

WebXR の inputsourceschange と primary action を、入力デバイスが消えた時の「安全な受け渡し」として観察する自作試作です。操作中の hand / controller / gaze は、別 source に黙って移し替えません。

ポリシー: selectstart を受けた source だけが select まで進める。途中で消えた場合は、残った source があっても action を cancel し、新しい明示操作を待つ。

次に足すなら

  1. 実 XRSession の inputsourceschange と selectstart / selectend を接続する。
  2. XRInputSourceEvent.frame を current animation frame と混同しない診断を加える。
  3. profile ごとの controller model を読み込む前に capability と同意を表示する。
