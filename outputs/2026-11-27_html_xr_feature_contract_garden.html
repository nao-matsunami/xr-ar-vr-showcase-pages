XR Feature Contract Garden

requiredFeatures と optionalFeatures を、見た目の豪華さではなく「開始できなければ困る条件」と「あれば育つ表現」に分ける自作の最小試作です。

session mode

各 feature をクリックして required / optional / off を巡回します。

設計規則: required が得られなければ開始を止める。optional が得られなければ、控えめな代替表現で続ける。probe 成功は session 成功の予約ではない。

feature receipt

次に足すなら

  1. 実機で requestSession() の結果から enabled feature と reference space を記録する。
  2. AR では camera / hit-test など情報量の高い feature を目的別の consent 文に分解する。
  3. 一つの immersive session が活動中なら、別体験への導線を「開始」ではなく待機に変える。
