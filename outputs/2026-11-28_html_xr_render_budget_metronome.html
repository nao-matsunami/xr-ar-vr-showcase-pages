Render Budget Metronome

XR 専用の frame loop を「描けたか」ではなく、次の repaint までに品質をどう落として守るかとして試す派生プロトタイプです。

規則: 11ms を超えたら新要素を確定しない。15ms を超えたら detail tier を下げ、前 frame の pose を描画に流用しません。

budget receipt

次に足すなら

  1. 実測 CPU / GPU timer と viewport scale を記録する。
  2. visibility が blurred-visible なら品質予算を別枠にする。
  3. 重い AI 推論は Worker に退避し、結果に frame freshness を付ける。
