Dynamic Viewport Scale Lab

自作の最小試作。WebXR の view ごとに、要求した縮尺がそのフレームの最初の getViewport() で確定する順序を、品質と HUD 保護に分けて観察します。

HUD TEXT
always protected
1.00 × viewport

各フレームで scale を request し、その view への最初の getViewport で適用します。縮める対象は背景の描画面であり、中央 HUD の文字そのものではありません。

frame receipt
requested scale: 1.00
first getViewport: pending
applied scale: 1.00
fallback policy: full quality
実機では view.requestViewportScale(scale) の後、同一フレームで baseLayer.getViewport(view) を呼びます。API が無い・無視された場合は、scene complexity を下げる別経路を取ります。
