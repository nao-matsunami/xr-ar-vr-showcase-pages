今日の重要トピックKey topics today

  1. WebXR Layers API Level 1 の最新 Editor's Draft は 2026-08-11 版で、`layers` feature descriptor、`XRWebGLBinding` / `XRMediaBinding`、`updateRenderState()` で composition layers を使う流れを示しています。 The latest WebXR Layers API Level 1 Editor's Draft is dated 2026-08-11 and describes the `layers` feature descriptor, `XRWebGLBinding` / `XRMediaBinding`, and `updateRenderState()` flow for composition layers.
  2. 同仕様は composition layers の利点として、compositor 側での滑らかな表示、レイヤーごとの解像度調整、テキストや地図の可読性維持を挙げています。 That specification lists smoother compositor presentation, per-layer resolution control, and maintaining text or map legibility as key benefits of composition layers.
  3. W3C の 2026-06-12 Working Draft では `XRQuadLayer` が 3D 空間内の平面矩形として定義され、`space`、`transform`、`width`、`height` を持つ UI 面として扱えます。 The W3C 2026-06-12 Working Draft defines `XRQuadLayer` as a flat rectangular surface in 3D space with `space`, `transform`, `width`, and `height`.
  4. MDN の `XRWebGLLayer.getNativeFramebufferScaleFactor()` は secure context / experimental / limited availability とされ、XR デバイスの native framebuffer 解像度に合わせるための scale factor を説明しています。 MDN marks `XRWebGLLayer.getNativeFramebufferScaleFactor()` as secure-context-only, experimental, and limited availability, and explains how it relates to native framebuffer resolution.
  5. Immersive Web の layers samples は projection / quad / cylinder / equirect / media layer や layer vs non-layer 比較を並べ、公式デモとして API 面の確認に使えます。 The Immersive Web layers samples provide official demos for projection, quad, cylinder, equirect, media layers, and layer-vs-non-layer comparison.

注目事例と何が面白いかNotable example and why it matters

今日の注目は WebXR Layers API の layers samples です。公式デモは projection、quad、cylinder、equirect、media layer などを API 単位で確認でき、特に layer vs non-layer 比較は「UI を通常のシーン描画に混ぜるか、composition layer として別解像度で持つか」という実装判断を考える材料になります。面白いのは、レイヤーが単なる描画最適化ではなく、テキスト、地図、警告パネルの可読性を守る UI 設計の単位になる点です。公開カードの中心には置かず、今日の自作サンプルではその発想を距離・角度・framebuffer scale・頭部揺れのスコアに置き換えました。

Today's notable reference is the WebXR Layers Samples. The official demos make projection, quad, cylinder, equirect, and media layers inspectable by API surface, and the layer-vs-non-layer comparison is useful for deciding whether UI should be drawn into the scene or kept as a composition layer at its own resolution. The interesting part is that layers are not just a rendering optimization; they can become the design unit for protecting text, map, and warning panel legibility. Instead of featuring those demos as archive cards, today's original sample turns that idea into a distance, angle, framebuffer scale, and head-jitter score.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプルでは、device profile、panel shape、distance、off-axis yaw、framebuffer scale、head jitter を触ると、`XRQuadLayer` / `XRCylinderLayer` / projection fallback のどれで表示すべきかと、読める UI として保てるかを即時に変えます。視覚表現は上から見た空間図で、HMD と世界固定パネルの距離・角度を線で見せています。派生サンプルでは、同じ verdict を `confirm` / `caution` / `block` / `visual-only` に分類し、12ステップの振動パルス列として可視化します。これにより、可読性や安全判定を reticle 色、DOM Overlay の理由表示、gamepad haptics へ同時に配れる設計になります。

The main sample changes device profile, panel shape, distance, off-axis yaw, framebuffer scale, and head jitter, then immediately resolves whether `XRQuadLayer`, `XRCylinderLayer`, or projection fallback should be used and whether the UI remains readable. The visual is a top-down spatial diagram connecting the HMD and world-locked panel. The derivative sample maps the same verdict into `confirm`, `caution`, `block`, or `visual-only`, then visualizes it as a 12-step vibration pulse pattern. This makes it easier to route readability or safety verdicts into reticle color, DOM Overlay reason text, and gamepad haptics together.

制作に使えそうな技術メモProduction note

実装時は `navigator.xr.requestSession("immersive-vr", { optionalFeatures: ["layers", "local-floor"] })` のように layers を optional feature として要求し、許可された場合だけ `XRWebGLBinding` や `XRMediaBinding` で quad / cylinder layer を作る流れにします。`inline` session では layers を使えないため、サンプルのように projection / canvas fallback を明示する必要があります。MDN の framebuffer scale factor は実機品質の基準作りに使えますが、limited availability かつ experimental なので、固定値 slider、FPS、テキストサイズ、実測読了時間を併用して診断するのが現実的です。ハプティックは `XRInputSource.gamepad` の有無で primary only / no haptics を分け、無い場合は視覚フィードバックへ縮退します。

A production implementation can request layers as optional with something like `navigator.xr.requestSession("immersive-vr", { optionalFeatures: ["layers", "local-floor"] })`, then create quad or cylinder layers with `XRWebGLBinding` or `XRMediaBinding` only when granted. Since inline sessions cannot use layers, projection or canvas fallback should be explicit. MDN's framebuffer scale factor is useful for device-quality baselines, but because it is limited availability and experimental, it is practical to combine it with fixed sliders, FPS, text size, and measured reading time. For haptics, branch on `XRInputSource.gamepad` support and fall back to visual feedback when actuators are missing.

サンプルデータの可能性と組み合わせSample data potential and combinations

今日の2本からは requested features、resolved layer、distance、off-axis yaw、framebuffer scale、head jitter、readability score、verdict、pulse amplitudes、fallback reason を取れます。2026-08-22 の bounded space verdict と合わせると、床の移動候補だけでなく、壁際や空中の世界固定パネルも同じ verdict pipeline に乗せられます。2026-08-15 の haptic queue と合わせれば、`block` は強めの断続パルス、`caution` は間隔を空けた注意パルス、`confirm` は短い二段パルスにできます。展示用途では、可読性スコアをスタッフ用 dashboard、来場者向け overlay、ログ保存に分岐できます。

The two samples emit requested features, resolved layer, distance, off-axis yaw, framebuffer scale, head jitter, readability score, verdict, pulse amplitudes, and fallback reason. Combined with the 2026-08-22 bounded-space verdict, the same verdict pipeline can cover not only floor locomotion targets but also wall-adjacent or floating world-locked panels. Combined with the 2026-08-15 haptic queue, `block` can become strong intermittent pulses, `caution` spaced warning pulses, and `confirm` a short two-step pulse. For installations, the readability score can branch into staff dashboards, visitor overlays, and log storage.
