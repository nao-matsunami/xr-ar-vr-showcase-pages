Yesterday saved visibility-mask changes as standalone rows and replayed them into a tile budget. Today puts those rows on the same diagnostic plane as the September 26 redraw timestamp, September 30 subimage viewport row, and September 29 viewport crop guard. An `XRVisibilityMaskChange` mesh explains where to draw, but not why fallback happened. Combining mask age, redraw age, crop mismatch, and head motion gives operators a reason for returning to full-viewport rendering.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Visibility Mask Row Merge Console` は view、mask age、redraw age、crop inset、head motion を動かし、merged route、saved pixels、risk score、patch band を出します。派生サンプル `Visibility Fallback Reason Replayer` は本命 row を貼り付け、mask / redraw / crop / motion のどれが fallback 理由として支配的かを分解します。体験としては、XR 描画の黒箱を「今日は mask が古い」「今日は crop mismatch が大きい」のように読める小さな診断盤です。

The main sample, `Visibility Mask Row Merge Console`, lets you adjust view, mask age, redraw age, crop inset, and head motion, then produces a merged route, saved pixels, risk score, and patch band. The derivative sample, `Visibility Fallback Reason Replayer`, accepts the main row and breaks down whether mask, redraw, crop, or motion dominates the fallback reason. As an experience, it turns XR rendering fallback from a black box into a small diagnostic board that can say things like `the mask is stale` or `crop mismatch is high`.

制作に使えそうな技術メモProduction note

実装では `viewId` を primary key にし、`visibility-mask-change`、`subimage-viewport-row`、`layer-redraw-timestamp` の3系統を同じ frame window で merge します。保存対象は vertices / indices / viewport / timestamp / age / route などの軽量 row に限定し、実 texture や camera frame は保存しません。古い mask は full viewport、軽い crop mismatch は patch band、redraw だけ古い場合は layer 更新待ち、と原因別に処理を分けると、性能と説明可能性の両方が上がります。

In production, use `viewId` as the primary key and merge `visibility-mask-change`, `subimage-viewport-row`, and `layer-redraw-timestamp` within the same frame window. Store only lightweight rows such as vertices / indices / viewport / timestamp / age / route, not textures or camera frames. Split causes into full viewport for stale masks, patch bands for light crop mismatch, and layer-update hold when only redraw is stale; this improves both performance and explainability.

サンプルデータの可能性と組み合わせSample data potential and combinations

今日の merged row は、遠隔支援、展示 UI、XR 業務手順のログ再生に向いています。ユーザーが見ていた範囲、実際に描いた範囲、省略した tile、fallback 理由を分けておくと、後から `なぜ一瞬重くなったか`、`どの目だけ mask がずれたか`、`どの layer が更新待ちだったか` を説明できます。AI 要約と組み合わせる場合も、実画像ではなく row を読むだけで、privacy-aware なセッション診断にできます。

Today's merged rows fit remote assistance, installation UI, and replay for XR operational procedures. Separating what the user could see, what was drawn, which tiles were skipped, and why fallback happened makes it possible to explain later why a frame became heavy, which eye had mask drift, or which layer was waiting for an update. When combined with AI summaries, the system can read rows instead of images, enabling privacy-aware session diagnostics.
