今日の重要トピックKey topics today

  1. WebXR Device API は XRInputSource と XRInputSourceEvent を通じ、入力の状態変化を session に結び付ける。 WebXR associates source state transitions with a session.
  2. inputsourceschange は利用可能な入力デバイス集合が変わった時に発火し、追加・削除を明示的に扱える。 inputsourceschange explicitly exposes added and removed devices.
  3. XRInputSourceEvent.frame はイベント時点の frame であり、現在の animation frame や viewer pose と同一視できない。 An input event frame is not the current animation frame.
  4. WebXR Gamepads Module は button、trigger、thumbstick、touchpad を扱うための拡張で、xr-standard mapping と platform reserved buttons を定義する。 The Gamepads Module defines controller data and mapping concerns.

注目事例と何が面白いかNotable example and why it matters

W3C の WebXR Device API は input source を session に属する観測として定義し、MDN は inputsourceschange をデバイスの追加・消失を検知するイベントとして整理しています。特に XRInputSourceEvent.frame は過去に render された event frame でもあり得るため、操作イベントを現在の pose と混ぜない設計が重要です。公式資料は根拠として参照し、公開アーカイブには外部デモ一覧ではなく自作の操作実験だけを並べます。

The event-frame distinction makes source changes a useful boundary for original interaction studies, rather than a reason to publish an external-demo list.

表現・インタラクションのアイデアExpression and interaction idea

本命 Input Source Relay Desk は hand / controller / gaze を接続・切断し、primary action の所有 source を一つだけ表示します。操作中の source を切断すると完了ではなく cancel と記録し、残存 source に引き継がないことを光と receipt で見せます。派生 Profile Receipt Mixer は profile によって primary action の意味を確かめ、未知 profile は preview のままにします。

The main visualizes an action owner and cancellation; the derivative turns profiles into cautious semantic capability receipts.

制作に使えそうな技術メモProduction note

実装では XRSession に inputsourceschange、selectstart、selectend、select を別々に登録し、removed source に紐づく連続操作を閉じます。event.inputSource の同一性で action owner を照合し、別 source の select を既存の操作の終端に変換しません。controller の軸や haptics は Gamepads Module の有無を確認し、targetRayMode・profiles・action capability を混ぜずに評価します。

Register source-set and action events separately; match ownership by source identity and negotiate controller capabilities independently.

サンプルデータの可能性と組み合わせSample data potential and combinations

保存するのは profile 名そのものや姿勢ではなく、source added / removed、action start / cancel / commit、capability 判定だけの小さな receipt がよいでしょう。展示なら source 切替を音色や線の編み直しへ、業務 UI なら機器交換時の安全な確認へ、教育では event frame と render frame の違いを示すログへ接続できます。11月25日の visibility 境界と組み合わせれば、不可視化と source 消失を同じ再確認規則で扱えます。

Minimal state receipts can drive audiovisual cues, operational recovery, and lifecycle teaching without retaining pose data.

俯瞰メモBird's-eye memo

XR の入力は「次に使える手段がある」ことと、「いま始まった意図を実行してよい」ことを分けると穏やかになります。手が消えた瞬間、別の controller を便利な代理人にするより、操作を一度静かに閉じるほうが、空間に対する利用者の因果感を守れます。

Availability and authority are different: closing an interrupted action can preserve agency better than silently relaying it.
