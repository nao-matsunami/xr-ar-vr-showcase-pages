  1. Immersive Web の WebXR WebGPU samples は `XRGPUBinding` と `XRProjectionLayer` を使う WebGPU XR の最小確認点として引き続き重要です。 Immersive Web WebXR WebGPU samples remain an important minimal checklist for WebGPU XR using `XRGPUBinding` and `XRProjectionLayer`.

  3. W3C WebXR Device API は 2026-06-09 Candidate Recommendation Draft が公開されており、session support / render state / layers 前提の土台です。 The W3C WebXR Device API 2026-06-09 Candidate Recommendation Draft is the base for session support, render state, and layer assumptions.
  4. W3C Depth Sensing Editor's Draft では WebGPU-compatible session 向けの `XRGPUDepthInformation` も言及され、depth row を WebGPU 側へ持ち込む理由があります。 The W3C Depth Sensing Editor's Draft mentions `XRGPUDepthInformation` for WebGPU-compatible sessions, which motivates carrying depth rows into the WebGPU path.
  5. Meta Browser 149.1 の release note は WebGPU support for space-warp layers を明記しており、起動前 probe に space-warp 候補を含める根拠になります。 Meta Browser 149.1 release notes explicitly mention WebGPU support for space-warp layers, giving a reason to include space-warp candidates in pre-start probes.

注目事例と何が面白いかNotable example and why it matters

Immersive Web WebGPU samples are a practical entry point for checking `XRGPUBinding` / `XRProjectionLayer` in WebGPU-rendered WebXR sessions. The WebXR-WebGPU Binding explainer / draft describes how WebGPU resources are provided to WebXR, and Meta Browser 149.1 WebGPU space-warp layer support makes it useful to store not just whether support exists, but which check caused a route to fall back.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `XR WebGPU Probe Store Console` は、`navigator.gpu`、`navigator.xr`、`isSessionSupported()`、Permissions-Policy、IndexedDB の可用性を probe row としてまとめ、保存件数と missing fields を見せます。派生サンプル `Probe Row Schema Route Replayer` は、その row を貼り付けるだけで schema fit、retry queue、起動直後 6 frame の route を再判定します。

The main sample, `XR WebGPU Probe Store Console`, combines `navigator.gpu`, `navigator.xr`, `isSessionSupported()`, Permissions-Policy, and IndexedDB availability into a probe row while showing saved count and missing fields. The derivative sample, `Probe Row Schema Route Replayer`, replays pasted rows through schema fit, retry queue, and six post-start frame routes.

制作に使えそうな技術メモProduction note

実機版の最小列は `secureContext`、`webgpuNavigator`、`gpuAdapterLikely`、`xrNavigator`、`sessionSupported`、`xrSpatialPolicyAllowed`、`cameraPolicyAllowed`、`indexedDbWritable`、`route` です。ここに WebXR-WebGPU Binding の `XRGPUBinding` / `XRProjectionLayer` probe、Depth Sensing の CPU / GPU usage、WebXR Layers の foveation / subimage 情報を段階的に足せます。

The minimal on-device columns are `secureContext`, `webgpuNavigator`, `gpuAdapterLikely`, `xrNavigator`, `sessionSupported`, `xrSpatialPolicyAllowed`, `cameraPolicyAllowed`, `indexedDbWritable`, and `route`. WebXR-WebGPU Binding `XRGPUBinding` / `XRProjectionLayer` probes, Depth Sensing CPU / GPU usage, and WebXR Layers foveation / subimage details can be added incrementally.
