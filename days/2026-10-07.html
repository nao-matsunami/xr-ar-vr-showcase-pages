表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Predictive Frame Budget Governor` は、GPU headroom、motion miss、depth stale、prediction confidence を操作し、次の frame route を `balanced-projection-layer`、`raise-foveation-keep-warp`、`drop-peripheral-redraw`、`reduce-foveation-and-hold-warp`、`full-render-safety-frame` に分けます。派生サンプル `Frame Budget Replay Comparator` は、その route が次の5フレームの synthetic outcome と合っていたかを見ます。体験としては、画質設定を後追いで動かすのではなく、1-2フレーム先の失敗を読む dashboard です。

The main sample, `Predictive Frame Budget Governor`, manipulates GPU headroom, motion miss, depth staleness, and prediction confidence, then classifies the next frame into `balanced-projection-layer`, `raise-foveation-keep-warp`, `drop-peripheral-redraw`, `reduce-foveation-and-hold-warp`, or `full-render-safety-frame`. The derivative sample, `Frame Budget Replay Comparator`, checks whether that route matched the next five synthetic frame outcomes. The interaction is a dashboard for reading failures one or two frames ahead rather than reacting after image quality has already dropped.

On device, storing projection-layer state from the WebGPU / WebXR binding path, Space Warp motion-vector texture readiness, Depth Sensing frame age, and `XRProjectionLayer.fixedFoveation` under one timestamp in IndexedDB would make it possible to compare predicted routes against observed frame time.

サンプルデータの可能性と組み合わせSample data potential and combinations

今日の governor row と replay row は、XR QA で `なぜこの frame だけ full render に戻したか`、`予測では foveation を上げたが、実際は depth delay で失敗した` という説明に使えます。動画、Gaussian Splatting、操作 UI、展示空間のログと組み合わせるなら、どの体験シーンで motion vector / depth / foveation のどれが支配的な失敗要因だったかを後からランキングできます。

Today's governor and replay rows are useful for XR QA explanations such as why a frame returned to full render or why a predicted foveation increase failed because of depth delay. Combined with video, Gaussian splatting, operational UI, or installation logs, the rows can later rank which scene was dominated by motion-vector, depth, or foveation failure.

今日のミニ試作候補Today's mini prototype candidate

本命として採用した候補は `Predictive Frame Budget Governor` です。何が動くか: GPU headroom、motion miss、depth stale、prediction confidence から stable budget、next frame ms、quality、risk、route を計算し、4本の状態 lane と needle で表示します。次に足すなら、実 `XRProjectionLayer.fixedFoveation`、motion vector texture readiness、depth frame age を IndexedDB に保存します。派生として `Frame Budget Replay Comparator` も実装しました。何が動くか: seed route と5フレームの synthetic outcome を比較し、予測一致、late reset、score を表示します。次に足すなら、1本目の export row を直接 paste / import し、実 headset session の frame time と比較します。

The selected main prototype is `Predictive Frame Budget Governor`. What it does: computes stable budget, next-frame milliseconds, quality, risk, and route from GPU headroom, motion miss, depth staleness, and prediction confidence, then displays four state lanes and a needle. Next addition: save real `XRProjectionLayer.fixedFoveation`, motion-vector texture readiness, and depth frame age to IndexedDB. The derivative `Frame Budget Replay Comparator` was also implemented. What it does: compares a seed route against five synthetic frame outcomes and displays prediction matches, late resets, and score. Next addition: directly paste / import the first sample's export row and compare it with real headset session frame time.
