注目事例と何が面白いかNotable example and why it matters

9月18日は `immersive-ar` の feature negotiation を row 化し、required / optional feature の欠落を後続の fallback policy へ渡せるようにしました。今日は、その session が始まったあとに問題になりやすい layer runtime を扱います。Layers API は可読性、動画、occlusion、multiview の改善に効きますが、`XRWebGLBinding` や media binding が見えない環境では、同じ UI を projection layer 内の mesh や通常 canvas に落とす必要があります。この drift を先に row 化しておくと、表示品質の差を後から説明できます。

On September 18, feature negotiation for `immersive-ar` became rows that can feed later fallback policies for required / optional feature gaps. Today moves to layer runtime, the next failure point after session startup. Layers API can improve readability, video, occlusion, and multiview rendering, but when `XRWebGLBinding` or media binding is not exposed, the same UI needs to fall back to projection-layer meshes or ordinary canvas rendering. Capturing that drift first makes later display quality differences explainable.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Layer Runtime Capability Drift Monitor` は secure context、`navigator.xr`、`isSessionSupported()`、`XRWebGLBinding`、`XRMediaBinding`、WebGL2、multiview extension を見て、projection / quad / cylinder / equirect / media layer ごとに native layer / guarded layer / projection fallback / screen row を判定します。派生サンプル `Layer Space Stability Route Sequencer` は layer type と intent、頭部揺れ、anchor confidence から `viewer`、`local`、`local-floor`、`bounded-floor`、anchor space を点数化し、選択 space と fallback 理由を短い timeline にします。

The main sample, `Layer Runtime Capability Drift Monitor`, checks secure context, `navigator.xr`, `isSessionSupported()`, `XRWebGLBinding`, `XRMediaBinding`, WebGL2, and multiview extensions, then routes projection / quad / cylinder / equirect / media layers to native layer, guarded layer, projection fallback, or screen row. The derivative `Layer Space Stability Route Sequencer` scores `viewer`, `local`, `local-floor`, `bounded-floor`, and anchor spaces from layer type, intent, head motion, and anchor confidence, then shows the selected space and fallback reason in a short timeline.

制作に使えそうな技術メモProduction note

`layers` を optional feature として session に渡し、session 開始後に `new XRWebGLBinding(session, gl)` が使えるかを確認する流れにすると、未対応端末でも session 自体は維持しやすくなります。quad / cylinder / equirect で世界固定 UI を作る時は、viewer space を便利な固定表示として使いすぎると位置・回転の再投影安定性を損ねるため、reticle 以外は local / local-floor / anchor space へ寄せる判定を持たせるのがよさそうです。

Passing `layers` as an optional session feature and checking whether `new XRWebGLBinding(session, gl)` works after startup helps keep the session alive on unsupported devices. When using quad / cylinder / equirect layers for world-locked UI, overusing viewer space as a convenient fixed display can hurt positional and rotational reprojection stability. For anything other than reticles, it is useful to route toward local / local-floor / anchor spaces.
