今日の重要トピックKey topics today

  1. WebXR Layers の writable 属性は XR animation frame callback の終端で compositor に送られ、次の提示で反映されます。 Writable layer properties commit at animation-frame end and apply at the next presentation.
  2. Composition Layers は immersive-vr / immersive-ar に限られ、追加 layer は `layers` feature の交渉が必要です。 Composition Layers are immersive-session features.
  3. quality は compositor への hint であり、可読性と追加処理・電力のトレードオフを端末ごとに測る必要があります。 Quality hints need device-specific readability and power measurements.
  4. WebGPU-backed layer の texture resource は GPUDevice の resource limit に属するため、時間とメモリを別々に記録します。 WebGPU layer resources belong to GPU device limits.

注目事例と何が面白いかNotable example and why it matters

Layers API は、属性をセットした瞬間と画面で見える瞬間を同一視しないモデルです。仕様上、書換え可能属性は rAF callback の終端で compositor へ送られ、その frame が次に提示される時に適用されます。本命はこの差を操作可能な receipt に縮めました。
