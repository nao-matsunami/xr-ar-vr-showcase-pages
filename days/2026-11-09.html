今日の重要トピックKey topics today

  1. WebXR Device API の bounded-floor は安全に動ける範囲を boundsGeometry で示す XRBoundedReferenceSpace である。 bounded-floor exposes a safe perimeter through XRBoundedReferenceSpace.
  2. XRReferenceSpace の reset は原点と環境の対応に不連続が生じたことを示す。 A reset signals a discontinuity between origin and environment.
  3. 参照空間は immutable で、オフセット移動は新しい reference space を作って扱う。 Reference spaces are immutable; offsets yield new spaces.
  4. 境界を取得できない場合は、境界があるように振る舞わず定点向け体験へ縮退する。 Missing boundaries need an honest stationary fallback.
  5. 境界付近の移動は警告一色にせず、余裕・確認・停止という段階にすると意図を保ちやすい。 Near-boundary movement benefits from graded intent handling.

注目事例と何が面白いかNotable example and why it matters

WebXR Device API は bounded-floor を、利用者が安全に動ける所定の境界を持つ XRBoundedReferenceSpace として定義します。今日の本命はこの境界を単なる床の輪郭ではなく、reset 時に古い前提をいったん止めて再確認へ導く状態機械として扱います。公式 sample index は機能ごとの最小実装を参照する入口として有用ですが、公開カードの主役はこの自作の操作可能な状態検証です。

表現・インタラクションのアイデアExpression and interaction idea

本命では live を mint の穏やかな囲い、reset を amber の再較正 cue、境界なしを赤い定点モードとして表します。派生では境界までの距離を余裕・0.35m・越境に分け、移動を allow / preview + confirm / block と段階化します。安全性を大きな警告だけにせず、利用者の移動意図と確認の余地を演出にします。

Visual cues distinguish live, reset, and missing boundaries; crossing intent gets graded policies.

制作に使えそうな技術メモProduction note

実機では利用者操作から session を開始し、requestReferenceSpace('bounded-floor') を試します。取得できれば boundsGeometry を描画し、reference space の reset を購読します。reset では既存の world-space 仮定を再検証し、必要なら新しい reference space とオフセットを用意します。対応しない端末では local-floor で定点向け UI に縮退します。

Request bounded-floor from user activation, observe reset, and use a stationary fallback when unavailable.

サンプルデータの可能性と組み合わせSample data potential and combinations

両試作は境界形状そのものを保存せず、距離帯・reset・移動許可・確認という判断 receipt だけを扱います。展示では音響の強さや照明を境界近傍で柔らかく変えられ、業務ARでは危険エリアへの誘導を confirm に置き換えられます。アンカー、ハンド入力、音声ガイドと組み合わせても、空間の詳細を外部へ出さない設計を保てます。

Decision receipts combine with audio, anchors, and guidance without retaining room geometry.

俯瞰メモBird's-eye memo

安全境界は「ここから先はだめ」という線より、空間の前提がまだ有効かを利用者と共有する対話です。追跡や部屋設定は変わり得るため、変化を隠して連続性を偽装するより、短い pause と再確認を体験のリズムに入れるほうが信頼を作れます。

A boundary is a dialogue about whether spatial assumptions remain valid, not merely a prohibition line.
