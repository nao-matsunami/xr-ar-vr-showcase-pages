今日の重要トピックKey topics today

  1. WebXR Device API は 2026-06-09 の Candidate Recommendation Draft が最新公開版で、`XRFrame.getPose(space, baseSpace)` は frame 時点の space 間 pose を返す入口です。 The latest published WebXR Device API is the 2026-06-09 Candidate Recommendation Draft, and `XRFrame.getPose(space, baseSpace)` is the entry point for a pose between spaces at a frame time.
  2. MDN の `XRInputSourceEvent.frame` は、event frame が通常の animation frame ではなく、入力が起きた時点の `getPose()` 用 frame である点を確認材料にできます。 MDN's `XRInputSourceEvent.frame` notes that the event frame is not a normal animation frame, but a frame for reading pose at the input time via `getPose()`.
  3. WebXR Gamepads Module は `XRInputSource.gamepad` が frame ごとに同じ object 上で更新されるため、比較には button / axes 値を行データとして cache する必要があります。 The WebXR Gamepads Module says `XRInputSource.gamepad` is updated in place every frame, so button and axes values must be cached as row data for comparisons.
  4. IndexedDB は structured data を非同期 transaction で保存できるため、XR 入力ログ、pose confidence、gamepad snapshot、commit route の蓄積に向いています。 IndexedDB stores structured data through asynchronous transactions, making it useful for XR input logs, pose confidence, gamepad snapshots, and commit routes.
  5. 今日の公開カードは外部デモではなく、このワークスペース内の `XR Input Log Store Lab` と `XR Log Replay Import Verifier` の2本です。 Today's public cards focus on the original workspace samples, `XR Input Log Store Lab` and `XR Log Replay Import Verifier`, not external demos.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `XR Input Log Store Lab` は、scenario、pose noise、frame gap を変えながら、XR 風の event row を IndexedDB に追記し、最新行の ray、pose availability、confidence、route を表示します。派生サンプル `XR Log Replay Import Verifier` は、1本目の exported JSON を貼り付けるか内蔵 seed log を読み込み、commit window と duplicate guard を変えて `commit`、`hold`、`retry`、`drop` を再計算します。

The main sample, `XR Input Log Store Lab`, changes scenario, pose noise, and frame gap while appending XR-like event rows to IndexedDB and showing the latest ray, pose availability, confidence, and route. The derivative sample, `XR Log Replay Import Verifier`, imports exported JSON from the first sample or a seed log, then recalculates `commit`, `hold`, `retry`, and `drop` as the commit window and duplicate guard change.

制作に使えそうな技術メモProduction note

`XRInputSourceEvent.frame` は event 時点の pose を読むための frame として扱い、実機版では `event.frame.getPose(event.inputSource.targetRaySpace, referenceSpace)` の結果、event timestamp、nearby animation frame timestamp、`XRInputSource.gamepad` の button / axes snapshot を同じ object として保存します。Gamepad object 自体は live に更新されるので参照を持ち回らず、数値だけを保存するのが安全です。保存先は IndexedDB の object store にして、あとで route 判定だけを差し替えられる行構造にします。

`XRInputSourceEvent.frame` should be treated as the frame for reading pose at event time. A device-backed version would store the result of `event.frame.getPose(event.inputSource.targetRaySpace, referenceSpace)`, event timestamp, nearby animation-frame timestamp, and numeric `XRInputSource.gamepad` button/axes snapshots in one object. Because the Gamepad object is live, avoid retaining the object reference and persist only numeric values. Store rows in an IndexedDB object store so routing decisions can be recalculated later.
