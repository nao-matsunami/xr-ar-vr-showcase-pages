今日の重要トピックKey topics today

  1. WebXR Layers API Level 1 は `XRLayer` の `redraw` event を定義し、layer resource loss や compositor が再投影できない場合に次の XR animation frame で描き直す流れを示しています。 WebXR Layers API Level 1 defines the `XRLayer` `redraw` event and describes the next-XR-animation-frame redraw path when layer resources are lost or the compositor can no longer reproject the layer.
  2. `space-warp` では motion vector texture または depth-stencil texture が処理対象 frame で提出されない場合、その frame は space warp が無効だったように処理されます。 For `space-warp`, if either the motion vector texture or depth-stencil texture is not submitted for a frame, that frame is processed as if space warp were not enabled.
  3. MDN の `XRLayerEvent` は `redraw` が layer 状態変化を表す event 型であり、resource loss / reprojection failure の合図として扱えることを整理しています。 MDN's `XRLayerEvent` page frames `redraw` as the event type for layer state changes, useful for resource loss and reprojection failure signals.
  4. Meta の WebXR Space Warp 資料は、app が motion vector と depth buffer を供給し、projection layer と texture-array を使う前提、さらに attachment サイズが color texture と異なる点を強調しています。 Meta's WebXR Space Warp documentation emphasizes app-provided motion vectors and depth buffers, projection layers with texture arrays, and attachment sizes that differ from the color texture.
  5. 今日の公開カードは外部デモではなく、自作の `XRLayer Redraw Timestamp Logger` と `Redraw Row Policy Replayer` の2本です。 Today's public cards are the original workspace samples `XRLayer Redraw Timestamp Logger` and `Redraw Row Policy Replayer`, not external demos.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `XRLayer Redraw Timestamp Logger` は layer event、depth attachment、motion vector attachment、frame timestamp gap、head motion から `redraw-next-frame`、`projection-fallback`、`disable-space-warp`、`rebuild-layer`、`hidden-hold`、`space-warp-continue` を出し、IndexedDB に保存できる JSON row を作ります。派生サンプル `Redraw Row Policy Replayer` はその row を貼り付け、strict / balanced / forgiving の3つの policy で再判定します。

The main sample, `XRLayer Redraw Timestamp Logger`, emits `redraw-next-frame`, `projection-fallback`, `disable-space-warp`, `rebuild-layer`, `hidden-hold`, or `space-warp-continue` from layer event, depth attachment, motion vector attachment, frame timestamp gap, and head motion, then creates JSON rows that can be stored in IndexedDB. The derivative `Redraw Row Policy Replayer` accepts those rows and reclassifies them with strict / balanced / forgiving policies.

制作に使えそうな技術メモProduction note

実装時は `XRLayer` に `redraw` listener を付け、次の XR animation frame timestamp と attachment availability を同じ row に入れると後から比較できます。`motionVectorTexture` と `depthStencilTexture` が揃っていない frame は warp 前提にしない、resource loss は描画 policy ではなく layer rebuild policy に寄せる、visibility hidden は route 判定を止めて hold する、という3つの分岐を先に作ると安全です。

In production, attach a `redraw` listener to `XRLayer` and store it with the next XR animation-frame timestamp and attachment availability. It is safer to make three early branches: frames without both `motionVectorTexture` and `depthStencilTexture` should not assume warp, resource loss should route to layer rebuild rather than visual policy, and hidden visibility should hold rather than continue route classification.
