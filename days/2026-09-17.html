注目事例と何が面白いかNotable example and why it matters

昨日は mesh が悪化した anchor を ghost replay に戻すところまで進めました。今日はその row を本当にブラウザ側へ保存し、次のサンプルへ JSON として渡す流れにしました。WebXR の公式仕様群は anchor、mesh、plane、depth を別々の API として定義しますが、実制作では `置いたものを翌日も信用できるか` を1つの履歴として扱う必要があります。IndexedDB はその履歴の最小保存先になり、semantic history は annotation を共有してよいかの説明可能な根拠になります。

Yesterday reached the point where anchors with degraded mesh support could return to ghost replay. Today turns that row into an actual browser-side saved record and passes it to the next sample as JSON. The WebXR specifications define anchors, meshes, planes, and depth as separate APIs, but production work needs a single history for whether a placed object can still be trusted tomorrow. IndexedDB becomes a minimal local store for that history, and semantic history gives explainable evidence for whether annotation should be shared.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Ghost Replay IndexedDB Logger` は anchor label、mesh score now / previous、plane stability、depth agreement、tracked anchor match、re-hit confidence、anchor age、persistent handle restored を操作し、`KEEP SOLID`、`RETURN TO GHOST`、`HOLD AND FADE`、`RE-HIT REQUIRED` に分けます。Save Row で IndexedDB に保存し、Export JSON で派生サンプルへ渡せる形式を出します。派生サンプル `Semantic History Import Replayer` は export JSON を貼り付け、semanticHistory、pose overlap、normal agreement、annotation risk から shared / split / ghost / block を判定します。

The main sample, `Ghost Replay IndexedDB Logger`, adjusts anchor label, current / previous mesh score, plane stability, depth agreement, tracked anchor match, re-hit confidence, anchor age, and persistent handle restore state, then routes to `KEEP SOLID`, `RETURN TO GHOST`, `HOLD AND FADE`, or `RE-HIT REQUIRED`. Save Row writes into IndexedDB, while Export JSON emits a payload for the derivative sample. The derivative `Semantic History Import Replayer` accepts that JSON and routes shared / split / ghost / block from semanticHistory, pose overlap, normal agreement, and annotation risk.

制作に使えそうな技術メモProduction note

実機版では、XR session 起動中の frame から anchor restore 結果、`frame.trackedAnchors`、mesh の `lastChangedTime` / `semanticLabel`、plane label / polygon stability、depth agreement を1 row にまとめ、IndexedDB へ保存します。サンプルでは合成値ですが、row の形は `id`、`savedAt`、`label`、`meshNow`、`meshPrev`、`plane`、`depth`、`tracked`、`rehit`、`age`、`restored`、`semanticHistory`、`route` にしてあります。まずは local-first にして、ユーザーが export した時だけ JSON を共有する設計にすると、実空間情報の扱いを慎重にできます。

A device-backed version can save anchor restore result, `frame.trackedAnchors`, mesh `lastChangedTime` / `semanticLabel`, plane label / polygon stability, and depth agreement into one IndexedDB row during an XR session. The sample uses synthetic values, but the row shape is `id`, `savedAt`, `label`, `meshNow`, `meshPrev`, `plane`, `depth`, `tracked`, `rehit`, `age`, `restored`, `semanticHistory`, and `route`. Keeping the flow local-first and only sharing JSON when the user exports it is a cautious way to handle real-world information.

Saving that change locally and feeding it back into annotation and display strength makes the experience much calmer.

今日のミニ試作候補Today's mini prototype candidate

本命として採用した候補は `Ghost Replay IndexedDB Logger` です。何が動くか: anchor label、mesh score now / previous、plane stability、depth agreement、tracked anchor match、re-hit confidence、anchor age、persistent handle restored を操作し、判定 row を IndexedDB に保存し、JSON export できます。次に足すなら、実 `immersive-ar` session の feature negotiation と `frame.trackedAnchors` / `detectedMeshes` をつなぎ、合成値ではなく実 frame から row を作ります。派生として `Semantic History Import Replayer` も実装しました。何が動くか: 1本目の export JSON または preset を読み込み、semanticHistory、pose overlap、normal agreement、annotation risk から shared / split / ghost / block を判定します。次に足すなら、import した row を anchor ごとに grouped timeline にして、同じ anchor の label が安定するまで annotation を ghost 表示にします。

The selected main prototype is `Ghost Replay IndexedDB Logger`. What it does: adjusts anchor label, current / previous mesh score, plane stability, depth agreement, tracked anchor match, re-hit confidence, anchor age, and persistent handle restore state, saves the decision row to IndexedDB, and exports JSON. Next addition: connect real `immersive-ar` feature negotiation and `frame.trackedAnchors` / `detectedMeshes` so rows are created from real frames instead of synthetic values. The derivative `Semantic History Import Replayer` was also implemented. What it does: imports the main sample's JSON or presets, then routes shared / split / ghost / block from semanticHistory, pose overlap, normal agreement, and annotation risk. Next addition: group imported rows by anchor and keep annotation ghosted until the same anchor's label stabilizes.
