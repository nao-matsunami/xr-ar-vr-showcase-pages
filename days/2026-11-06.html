今日の重要トピックKey topics today

  1. Hand Input Module の 2026年10月29日 Working Draft は handTracking.frequencyHint に default / high を定義する。 The October 29 draft defines default and high hand-tracking frequency hints.
  2. high は応答性を望む hint であり、実装は電力・熱・プライバシーなどにより無視または変更できる。 High is a request, not a guaranteed rate.
  3. XRFrame.getJointPose() は frame 時点の関節 pose を返し、利用不能なら null になり得る。 Joint poses are frame-bound and may be null.
  4. ピンチは select と squeeze の双方に重なり得るため、対象距離と確認で一意の route を設計する。 Pinch can overlap select and squeeze, so routing must be explicit.
  5. 手追跡は明示同意と匿名化を必要とし、high 指定でも保護は緩和されない。 Consent and anonymization remain required.

注目事例と何が面白いかNotable example and why it matters

W3C の Hand Input Module は、articulated hand pose を WebXR 入力として扱い、最新の draft では frequencyHint を default / high で表します。興味深いのは high が追加サンプルを要求する命令ではなく、応答性・安定性・電力のトレードオフを UA に伝える希望である点です。本命はその不確実性を隠さず、sample age、jitter budget、pose の欠落を別々に見せます。

The module treats high frequency as a preference rather than an instruction; the main prototype exposes age, jitter, and missing pose separately.

表現・インタラクションのアイデアExpression and interaction idea

本命では mint を安定した既定 cadence、amber を high 要望時の device-dependent な揺れ、red を pose 不可として描きます。派生では far pinch を select、near pinch を grasp、曖昧な距離を confirm に一意に振り分けます。視覚的には一つの手の閉じ動作でも、アプリの意味付けは一度しか実行しない設計です。

The main maps confidence to color; the derivative routes one closure to exactly one action.

制作に使えそうな技術メモProduction note

実機では immersive-vr / immersive-ar requestSession の requiredFeatures に hand-tracking を含め、必要なら handTracking:{frequencyHint:'high'} を渡します。各 XRInputSource.hand を確認し、XRFrame 内で getJointPose(joint, referenceSpace) を読む際は null を通常の状態として扱います。提示頻度は保証されないため、選択には dwell、距離しきい値、release、明示確認を組み合わせます。

Request hand-tracking, treat null pose normally, and combine dwell, thresholds, release, and confirmation.

サンプルデータの可能性と組み合わせSample data potential and combinations

receipt は frequency hint、sample age、jitter の扱い、対象距離、最終 route だけを残します。展示では手の存在を抽象的な光に置換し、トレーニングでは意図分離ログを振り返り、業務ARでは確認が必要な操作だけをハイライトできます。関節座標列そのものを保存しないため、演出・分析・安全UIをつなぎつつ個人性の高い生データを避けられます。

Policy receipts can power exhibits, training, and operational AR without storing joint-coordinate histories.

俯瞰メモBird's-eye memo

手追跡は自然な入力に見えますが、観測の頻度・欠落・意味付けは端末とアプリが共同で決める部分です。フレームごとの値を即時の確定操作に直結せず、追跡品質と意図の分岐を見える化すれば、XR の身体性と誤操作への強さを両立できます。

Visible uncertainty and intent routing make embodied input more resilient than immediate commit.
