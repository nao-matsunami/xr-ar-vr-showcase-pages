注目事例と何が面白いかNotable example and why it matters

Meta Browser の release notes では、149.1 に WebGPU support for space-warp layers、150.1 に experimental support for foveation to WebGPU in WebXR が並びます。W3C WebXR Layers では `XRProjectionLayer.fixedFoveation` が次の `XRFrame` で反映される性質を確認でき、Immersive Web の WebGPU samples は `XRGPUBinding` と `XRProjectionLayer` の入口を示しています。面白いのは、画質調整を単発の slider ではなく、`予測 row` と `観測 row` の差分として蓄積できる点です。

Meta Browser release notes list WebGPU support for space-warp layers in 149.1 and experimental WebGPU foveation support in WebXR in 150.1. W3C WebXR Layers documents that `XRProjectionLayer.fixedFoveation` changes take effect at the next `XRFrame`, while Immersive Web WebGPU samples provide an entry point for `XRGPUBinding` and `XRProjectionLayer`. The interesting part is treating quality adjustment as an accumulated diff between predicted rows and observed rows, not as a one-off slider.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Frame Telemetry Schema Mapper` は、10月4日の prediction、10月5日の depth-motion、10月6日の foveation、10月7日の frame-budget を source day として選び、frameMs、motionErrorPx、depthAgeMs、fixedFoveation を共通 observation row に正規化します。派生サンプル `Prediction Observation Diff Replayer` は、その row から予測 route と観測 route のズレを6フレームで再生します。体験としては、毎日の小さな試作を実機 QA の同じログ形式へ寄せる橋です。

The main sample, `Frame Telemetry Schema Mapper`, lets you choose October 4 prediction, October 5 depth-motion, October 6 foveation, or October 7 frame-budget as the source day, then normalizes frameMs, motionErrorPx, depthAgeMs, and fixedFoveation into a shared observation row. The derivative sample, `Prediction Observation Diff Replayer`, replays the mismatch between predicted and observed routes across six frames. The interaction is a bridge from daily prototypes into one headset-QA log format.

制作に使えそうな技術メモProduction note

今日の schema は `timestamp`、`frameMs`、`motionErrorPx`、`depthAgeMs`、`fixedFoveation`、`predictedRoute`、`observedRoute` を必須候補にしました。実機版では `XRFrame` timestamp、WebGPU / WebXR binding の projection layer 状態、Depth Sensing の frame age、motion vector texture readiness、`XRProjectionLayer.fixedFoveation` を同じ row に保存し、予測と観測の route flip を再生できるようにします。

Today's schema treats `timestamp`, `frameMs`, `motionErrorPx`, `depthAgeMs`, `fixedFoveation`, `predictedRoute`, and `observedRoute` as required candidates. On device, the `XRFrame` timestamp, projection-layer state from the WebGPU / WebXR binding path, Depth Sensing frame age, motion-vector texture readiness, and `XRProjectionLayer.fixedFoveation` should be saved into one row so route flips between prediction and observation can be replayed.

サンプルデータの可能性と組み合わせSample data potential and combinations

今日の observation row と diff row は、実機 QA、展示ログ、Gaussian Splatting の LOD 制御、360動画の decode / render budget、操作 UI の品質説明に使えます。たとえば `motionErrorPx が高い時は splat LOD を落とす`、`depthAgeMs が古い時は occlusion を hold する`、`fixedFoveation を上げたのに frameMs が改善しない時は shader path を疑う` という分析に接続できます。

Today's observation and diff rows can support headset QA, installation logs, Gaussian splatting LOD control, 360-video decode / render budgets, and operational UI explanations. Example uses include lowering splat LOD when `motionErrorPx` is high, holding occlusion when `depthAgeMs` is stale, or questioning the shader path when raising `fixedFoveation` does not improve `frameMs`.
