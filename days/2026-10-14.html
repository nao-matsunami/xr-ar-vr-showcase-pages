Meta の WebXR Space Warp 資料は depth buffer と motion vector を smooth motion の材料として扱うため、`enable space warp` の UI は depth / motion の両方を gate にするのが自然です。 Meta's WebXR Space Warp documentation treats depth buffers and motion vectors as inputs for smooth motion, so an `enable space warp` UI naturally needs both depth and motion gates.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `XR Capability Action Gateboard` は profile、session mode、frame spare、hands UI、DOM overlay を切り替えながら、runtime probe を action gate に変換します。派生サンプル `Action Gate History Replayer` は、本命サンプルの row を貼り付け、stable / flapping / new feature spike の履歴と照合して、8 frame の間に primary route へ戻せるかを再生します。

The main sample, `XR Capability Action Gateboard`, converts runtime probes into action gates while switching profile, session mode, frame spare, hands UI, and DOM overlay. The derivative sample, `Action Gate History Replayer`, accepts the main sample's row, compares it against stable / flapping / new feature spike history, and replays whether the primary route can be restored within eight frames.

The selected main prototype is `XR Capability Action Gateboard`. What it does: switches profile, mode, frame spare, hands UI, and DOM overlay, then emits enabled / degraded / probe states for actions based on WebGPU / WebXR / Layers / Depth / Motion / Policy gates. Next addition: save real exception names from `requestAdapter({ xrCompatible: true })`, `requestSession()`, `XRGPUBinding`, and Space Warp attachments into IndexedDB. What it does: accepts the first row, compares it with stable / flapping / new feature spike history, and decides whether the primary route can be restored within eight frames. Next addition: generate history from previous `reports` or probe store rows and tune UI restoration cooldown with real data.
