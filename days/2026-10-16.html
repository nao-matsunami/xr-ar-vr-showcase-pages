今日の重要トピックKey topics today

  1. WebXR Hand Input は `hand-tracking` feature を要求した session で、XRInputSource の25関節を pose として取得できます。 WebXR Hand Input exposes 25 hand-joint poses through XRInputSource in sessions requesting the hand-tracking feature.
  2. `XRFrame.getJointPose()` は frame 時刻の pose を返し、追跡がない時は null になりうるため、欠落を通常のピンチと同じ扱いにしない設計が必要です。 XRFrame.getJointPose() returns a pose at the frame time and can return null, so tracking loss needs a different route from a regular pinch.
  3. Meta WebXR Hands では hands は controller と並ぶ XRInputSource で、通常ピンチとシステム予約の palm pinch を区別します。 Meta WebXR Hands presents hands alongside controllers and distinguishes regular pinch from system-reserved palm pinch.
  4. 短い連続 frame window と duplicate guard を置くと、jitter や再発見で select candidate が連打されるのを防げます。 A short consecutive-frame window plus a duplicate guard prevents repeated select candidates during jitter or reacquisition.

注目事例と何が面白いかNotable example and why it matters

W3C の Hand Input は手の骨格を高レベル gesture ではなく joint pose として渡します。Meta は通常ピンチを emulated gamepad の button press として扱いつつ palm pinch を system 用に予約します。本命はこの両者の間を埋め、pose の有無・tip gap・stability・event を説明可能な1 rowへ変換します。

W3C Hand Input exposes hand skeletons as joint poses rather than high-level gestures. Meta treats regular pinch as an emulated gamepad press while reserving palm pinch for the system. The main sample turns pose availability, tip gap, stability, and events into one explainable row.

表現・インタラクションのアイデアExpression and interaction idea

本命 `Hand Joint Event Logbook` は XR 開始ボタンで immersive VR と `hand-tracking` を optional 要求し、index/thumb tip の gap を読む経路を持ちます。機材がない時は synthetic row を記録できます。派生 `Hand Log Threshold Replayer` はその row と clean / bounce / loss / reserved の8 frameを重ね、端末別に commit をいつ許すかを可視化します。

The main Hand Joint Event Logbook optionally requests immersive VR and hand-tracking and includes a path to read index/thumb tip gaps. Without hardware it records synthetic rows. The derivative overlays that row with eight clean, bounce, loss, or reserved frames to visualize device-specific commit timing.

制作に使えそうな技術メモProduction note

最小 schema は `timestamp`、`event`、`tipGapMm`、`jointTracking`、`stability`、`systemReserved`、`confidence`、`route`、`reason` です。実機では `inputSource.hand.get('index-finger-tip')` と `thumb-tip` を `frame.getJointPose()` で読み、null は `reacquire` に落とします。session の `select` event は同じ ledger へ入れ、ポーズの観測結果と action との時差を後から見られるようにします。

The minimal schema is timestamp, event, tipGapMm, jointTracking, stability, systemReserved, confidence, route, and reason. On device, read index-finger-tip and thumb-tip with frame.getJointPose(), route null to reacquire, and store session select events in the same ledger.
