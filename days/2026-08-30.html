制作に使えそうな技術メモProduction note

`XRInputSource.gamepad` は通常の Gamepad API と似た形に見えますが、XR の action 判定では `XRSession.requestAnimationFrame()` の周期、input source lifecycle、pose availability とセットで扱うのが安全です。event を即 dispatch する前に短い hold window を置き、近い XR frame の button / axis 値で confirmation を取ると、stale frame、source removal、late confirmation、二重発火をログに分けられます。

`XRInputSource.gamepad` resembles the regular Gamepad API, but XR action decisions are safer when treated together with the `XRSession.requestAnimationFrame()` cadence, input-source lifecycle, and pose availability. Holding briefly before dispatching an event and confirming with nearby XR-frame button/axis values separates stale frames, source removal, late confirmation, and duplicate firing in logs.
