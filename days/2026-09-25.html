今日の重要トピックKey topics today

  1. W3C WebXR Device API は 2026年6月9日の Candidate Recommendation Draft が最新公開版で、session lifecycle、input、visibility、permissions policy を横断する基準になります。 The W3C WebXR Device API Candidate Recommendation Draft dated June 9, 2026 remains the latest published anchor for session lifecycle, input, visibility, and permissions policy behavior.
  2. WebXR Layers API Level 1 は 2026年8月11日の Draft Standard として一覧に出ており、`XRLayer`、composition layer、`redraw` event、`depth-sorted-layers`、`space-warp` の扱いを確認できます。 WebXR Layers API Level 1 appears in the W3C index as an August 11, 2026 Draft Standard, covering `XRLayer`, composition layers, `redraw` events, `depth-sorted-layers`, and `space-warp`.
  3. Layers API では `redraw` event が layer resource loss や compositor が再投影できない場合に発火し、著者は次の XR animation frame で描き直すべきだとされています。 The Layers API says a `redraw` event can fire when layer resources are lost or the compositor can no longer reproject the layer, and authors should redraw at the next XR animation frame.
  4. `space-warp` では depth / motion vector attachment が揃わない frame は space warp なしとして扱うため、欠落時の fallback route をログに残す価値があります。 For `space-warp`, a frame missing depth or motion vector attachments is processed as if space warp were not enabled, so logging the fallback route is useful.
  5. 今日の公開カードは外部デモではなく、自作の `Space Warp Layer Recovery Console` と `Motion Vector Gap Heatmap` の2本です。 Today's public cards are the original workspace samples `Space Warp Layer Recovery Console` and `Motion Vector Gap Heatmap`, not external demos.

注目事例と何が面白いかNotable example and why it matters

9月24日は DOM Overlay の focus 復帰と pinch / gaze intent の debounce を扱いました。今日は視線や手前の UI ではなく、XR compositor 側の復帰問題へ寄せます。WebXR Layers API では quad / cylinder / projection layer を composition layer として扱えますが、resource loss、`redraw`、depth sorting、space-warp の attachment 欠落が別々に見えると、実装側は `描き直す`、`warp を止める`、`projection fallback へ退避する` の判断を後追いでしかできません。そこを1行の recovery row にまとめるのが今日の面白い点です。

September 24 focused on DOM Overlay focus recovery and pinch / gaze intent debouncing. Today moves from front-facing UI to compositor recovery. WebXR Layers API lets authors use quad, cylinder, and projection layers as composition layers, but resource loss, `redraw`, depth sorting, and missing space-warp attachments can otherwise feel like separate failures. Implementations then decide too late whether to redraw, disable warp, or fall back to projection. Today's main idea is to turn those signals into one recovery row.

表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `Space Warp Layer Recovery Console` は layer event、feature descriptor、depth attachment、motion vector attachment、missed frames、head motion から `space-warp-continue`、`redraw-next-frame`、`disable-space-warp`、`rebuild-layer`、`hold-hidden`、`depth-sort-commit` を出します。派生サンプル `Motion Vector Gap Heatmap` は motion vector の穴をタイル heatmap として見せ、`use-vector`、`patch-vector`、`hold-depth`、`disable-warp` を判定します。

The main sample, `Space Warp Layer Recovery Console`, emits `space-warp-continue`, `redraw-next-frame`, `disable-space-warp`, `rebuild-layer`, `hold-hidden`, or `depth-sort-commit` from layer event, feature descriptor, depth attachment, motion vector attachment, missed frames, and head motion. The derivative `Motion Vector Gap Heatmap` shows vector gaps as tiled heat and classifies them as `use-vector`, `patch-vector`, `hold-depth`, or `disable-warp`.

制作に使えそうな技術メモProduction note

Layer 復帰ログは `redraw` を受けた事実だけでなく、session visibility、feature descriptor、depth texture / motion vector texture の新鮮さ、missed frame 数、head motion、fallback route を同じ JSON row に保存すると replay しやすいです。`space-warp` が使える端末でも attachment が片方欠けた frame は通常 frame として扱う前提にし、演出側では `warp 継続` と `見た目だけ保持` を分けておくと、急なぐらつきを説明できます。

For layer recovery logs, store not only the fact that `redraw` fired but also session visibility, feature descriptor, depth / motion vector freshness, missed frame count, head motion, and fallback route in the same JSON row. Even on devices that support `space-warp`, treat frames missing either attachment as normal frames, and separate visual hold from warp continuation so sudden instability can be explained.
