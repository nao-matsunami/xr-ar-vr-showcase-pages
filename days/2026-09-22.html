表現・インタラクションのアイデアExpression and interaction idea

本命サンプル `XR Bootstrap Probe Context Recorder` は intent、required coverage、optional coverage、probe confidence、privacy grain、TTL を操作し、`Run navigator.xr probe` で実ブラウザの XR 入口を確認して context row を作ります。派生サンプル `Trust Floor Injection Replayer` は、その JSON または seed context を読み、input / hit / anchor / layer row に最低 trust floor を注入して commit / guard / preview / drop を比較します。

The main sample, `XR Bootstrap Probe Context Recorder`, lets you adjust intent, required coverage, optional coverage, probe confidence, privacy grain, and TTL, then uses `Run navigator.xr probe` to check the browser's XR entry point and build a context row. The derivative sample, `Trust Floor Injection Replayer`, reads that JSON or a seed context and injects a minimum trust floor into input / hit / anchor / layer rows to compare commit / guard / preview / drop.

制作に使えそうな技術メモProduction note

実装では `requestSession()` の結果だけを保存するより、`isSessionSupported()`、requested features、granted features、optional gaps、privacy grain、TTL を同じ row にしておく方が replay と説明に強くなります。`enabledFeatures` は対応ブラウザが限られるため、取得できる時だけ採用し、取れない時は requested / manual coverage / probe result から低めの contextScore を出す設計が扱いやすいです。

In production, saving only the `requestSession()` result is less useful than storing `isSessionSupported()`, requested features, granted features, optional gaps, privacy grain, and TTL in one row. Because `enabledFeatures` has limited browser support, it is practical to use it when available and otherwise calculate a conservative contextScore from requested features, manual coverage, and probe results.
