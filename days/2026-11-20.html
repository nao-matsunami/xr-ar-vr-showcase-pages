今日の重要トピックKey topics today

  1. Dynamic Viewport Scaling は XRView ごとに opt-in する高頻度の解像度調整手段である。 Dynamic viewport scaling is an opt-in, per-XRView fine-grained resolution control.
  2. requestViewportScale() は希望であり、実効サイズは getViewport() の返り値で確認する。 The request is intent; getViewport() is the observed result.
  3. 対応しない実装では要求が無視されるため、描画負荷を下げる代替経路が必要になる。 Unsupported implementations need a scene-complexity fallback.
  4. framebuffer の再確保を伴う scale 変更と、viewport の細かな変更は別の使い分けになる。 Framebuffer reallocations differ from frequent viewport adjustments.
  5. 低い scale では文字と選択対象を先に守り、装飾と履歴表現を後から削る。 Protect readable text and interaction before flair.

注目事例と何が面白いかNotable example and why it matters

Immersive Web の Device API explainer は、dynamic viewport scaling を頻繁に変化する描画解像度向けの opt-in 機能として説明しています。XRView.requestViewportScale(scale) の後、XRWebGLLayer.getViewport(view) が同一 frame の実効 viewport を返します。要求をしたという UI 表示だけでは足りず、返り値を読むことで初めて品質制御が現実の GPU 資源と結び付く点が面白いところです。

The interesting contract is between an app request and the viewport actually returned for that frame.

表現・インタラクションのアイデアExpression and interaction idea

本命 Viewport Scale Contract Lab は full、UA 推奨、負荷時、未対応という4状態を切り替え、request と returned viewport、画素予算、代替経路を比較します。派生 Viewport Scale Quality Router は返った scale ごとに、文字・選択対象、空間文脈、影・粒子・history の順に予算を配ることで、単なるぼかしではない品質低下を試します。

The derivative routes the budget by semantic importance instead of applying a uniform blur.

制作に使えそうな技術メモProduction note

実装は pose.views を固定の左右2枚として扱わず、各 view に requestViewportScale があるかを確認して呼びます。その後に getViewport(view) を読み、gl.viewport と render target をそのサイズに合わせます。API が無い、または返り値が変わらないときは連続リトライせず、LOD・影・透明物・更新頻度を下げる fallback を選びます。頻繁な調整には viewport scale を使い、XRWebGLLayer の framebufferScaleFactor 再作成はまれなモード遷移に限ります。

Check per-view support, render to the observed viewport, and fall back to complexity and update-rate reductions.

俯瞰メモBird's-eye memo

XR の画素数は単独の品質つまみではなく、frame の到着、view の数、GPU の余白、可読性と結び付く共有資源です。request の数字だけを保存すると、互換性の違いや UA の判断をアプリ側の意図と取り違えます。観測値と表現の優先順位を分けると、解像度の変化を壊れた画面ではなく、理解できる品質遷移として設計できます。

Pixels are shared XR resources; separating requests from observations turns resolution shifts into comprehensible mode changes.
