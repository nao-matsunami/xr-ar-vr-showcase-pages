今日の重要トピックKey topics today

  1. WebXR hand input は手を XRInputSource として扱い、25個の skeleton joint pose を gesture recognition や描画に利用できます。 WebXR hand input exposes hands as XRInputSource objects and supplies 25 skeleton joint poses for gesture recognition or rendering.
  2. Meta の WebXR Hands は、通常ピンチが emulated gamepad の button press として扱われる一方、palm pinch はシステム予約であることを説明しています。 Meta WebXR Hands describes regular pinch as an emulated gamepad button while reserving palm pinch for system use.
  3. 手とコントローラは並行して現れうるため、どちらが primary input かを gesture 判定とは別の gate にする必要があります。 Hands and controllers can coexist, so primary-input ownership needs a gate separate from gesture detection.
  4. 関節 pose の欠落や jitter は即時 select より preview / reacquire へ落とすほうが、誤発火の理由を説明しやすくなります。 Joint-pose loss and jitter are easier to explain when routed to preview or reacquire instead of immediate select.

注目事例と何が面白いかNotable example and why it matters

Meta の WebXR Hands は、hands が controller と同じく XRInputSource として現れ、25関節の pose を gesture recognition に使えること、通常の pinch とシステム予約の palm pinch を区別すべきことを示します。今日の本命はその区別を UI decision に変換し、system gesture をアプリの選択として誤処理しない設計を小さく検証します。

Meta WebXR Hands shows that hands arrive as XRInputSource objects with 25 joint poses for gesture recognition and that regular pinch must be distinguished from system-reserved palm pinch. The main prototype turns that distinction into a small UI decision system.

表現・インタラクションのアイデアExpression and interaction idea

本命 `Hand Pinch Intent Gateboard` は tip distance、joint tracking、motion stability、gesture ownership、controller takeover を変え、commit / preview / hold / block の理由を row 化します。派生 `Pinch Commit Window Replayer` はその row を受け、連続する数 frame が閉じ・安定の条件を満たした時だけ1回の select candidate を出します。

The main gateboard changes tip distance, joint tracking, motion stability, gesture ownership, and controller takeover to emit reasons for commit, preview, hold, or block. The derivative replays the row and emits one select candidate only after a few contiguous good frames.

制作に使えそうな技術メモProduction note

実装 row は `tipDistanceMm`、`jointTracking`、`motionStability`、`gesture`、`controllerActive`、`confidence`、`intent`、`route`、`hold` を最小にします。実機では `XRInputSource.hand` の index-finger-tip と thumb-tip を `XRFrame.getJointPose()` または `fillPoses()` で読み、`selectstart` / `select` / `selectend` の timestamp と同じログへ保存します。

Keep `tipDistanceMm`, `jointTracking`, `motionStability`, `gesture`, `controllerActive`, `confidence`, `intent`, `route`, and `hold` in the minimal row. On device, read index-finger-tip and thumb-tip via `XRFrame.getJointPose()` or `fillPoses()` and store them with select-event timestamps.
