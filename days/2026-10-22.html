今日の重要トピックKey topics today

  1. WebXR Layers の needsRedraw は resource loss や compositor が再投影できない時に次の XR frame での描画を求めます。 needsRedraw requests a next-frame redraw.
  2. 非 projection の composition layer は redraw event を受けられ、static layer は作成後または redraw 後に描画します。 Static non-projection layers react to redraw lifecycle.
  3. WebXR-WebGPU Binding では、compositor が texture set を使い終えるまで backing resource を解放しません。 WebGPU textures remain leased until compositor access ends.
  4. Layers は解像度や静的 content の扱いを分けられるため、HUD の可読性と scene の GPU 負荷を別々に最適化できます。 Layers separate HUD legibility from scene GPU cost.

注目事例と何が面白いかNotable example and why it matters

Layers Samples は静的 quad layer、destroy、media、projection layer の分離を実例化しています。仕様の重要点は、needsRedraw が単なる UI 更新通知ではなく、underlying resources の損失や再投影不能を描画側へ戻す lifecycle 信号であることです。本命はその信号を texture の返却時刻まで追う操作画面にしました。

The main turns redraw from a flag into a texture-lifetime receipt.

Role-specific layer leases make a hidden lifecycle legible.
