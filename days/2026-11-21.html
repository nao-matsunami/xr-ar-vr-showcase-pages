今日の重要トピックKey topics today

  1. W3C の Hand Input Working Draft は hand-tracking を明示的な session feature とし、関節 pose は一式得られるか null として扱う設計を示す。 Hand input makes tracking an explicit session feature and treats hand poses as present or absent.
  2. W3C Immersive Web は 2026年10月に Hand Input の新しい Working Draft を公開し、更新頻度の hint を追加した。 A 2026 Working Draft adds a hand-tracking frequency hint.
  3. Depth Sensing は現実との物理的相互作用、遮蔽、非視覚的な環境認識を用途として挙げる。 Depth sensing supports physical interaction, occlusion, and environment awareness.
  4. WebXR Device API はコントローラ、光学追跡された手、視線を XR input source の例として扱う。 WebXR accepts controllers, tracked hands, and gaze as XR input sources.

注目事例と何が面白いかNotable example and why it matters

W3C の Hand Input Module は、articulated hand pose を session の hand-tracking feature として要求する構造にしています。さらに、手が一部隠れた場合は全関節を補間するか全体を null にする、と定めます。これは「少しだけ残った古い指先」を UI が本物らしく見せないための重要な境界です。Depth Sensing は遮蔽を代表的な用途に挙げており、手と深度のどちらも“取れた値”と“取れない値”を表現の条件にするのが面白い点です。

Both specifications make absence a first-class condition, which is useful for coherent spatial feedback.

表現・インタラクションのアイデアExpression and interaction idea

本命 Hand Signal Loom は、二つの合成 tip が近づくと線ではなく短い織り目を残し、片手を隠すと古い位置に留めず null pose に切り替えます。派生 Occlusion Rhythm Notebook は、光点を遮蔽物の前後に描き分け、奥に入る／出るリズムだけを抜き出します。どちらも不確かさを赤いエラーにせず、次に何が観測できれば再開するかを読める表示にします。

The main uses weaving marks for two tips; the derivative makes front/back ordering visible with particles.

制作に使えそうな技術メモProduction note

実装では requestSession の optionalFeatures か requiredFeatures に hand-tracking を明示し、inputSource.hand、各 XRJointSpace、getJointPose の戻り値を同一 frame で判定します。null pose を前 frame の座標で埋めず、短いフェードか入力保留にします。Depth Sensing は depth data の更新時刻、座標変換、信頼度を一緒に見て、欠けた frame では遮蔽を無効化する fallback を持たせます。WebXR は HTTPS の secure context が必要で、実機の対応範囲も確認します。

Check live hand and joint poses per frame; use an explicit no-occlusion fallback when depth is unavailable.

サンプルデータの可能性と組み合わせSample data potential and combinations

残すなら空間座標そのものではなく、joint の利用可否、近接した時刻、遮蔽の前後、fallback に入った理由という小さな receipt が適しています。展示の照明変化、触覚フィードバック、音のアタック、遠隔支援の確認 UI と結ぶと、追跡の不確かさを身体データの保存なしで体験演出に変えられます。

Availability and transition receipts can join audio, haptics, and assistance UIs without preserving spatial traces.

俯瞰メモBird's-eye memo

空間体験では、常に正確に見えることより、何が今は観測可能かを利用者が理解できることが信頼につながります。手の null pose と depth の欠損を描画バグとして隠すのではなく、表現のテンポに組み込むと、対応機種差や照明条件の変動にも耐える体験になります。

Making observability legible is more trustworthy than pretending spatial data is always precise.
